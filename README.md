A C programming project based on the japanese logic puzzle game called Futoshiki. The objective of the game is to fill a grid with numbers while following specific rules of each row and column must contain unique numbers and the numbers must satisfy the inequality signs (< and >) between adjacent cells. The user can select 4x4 5x5 or 6x6 grid. 

The program can be run by downloading the file in the release section

Built as a project for Hack Club's Crescent YSWS [You Ship We Ship] Program under the category Wildcard.
